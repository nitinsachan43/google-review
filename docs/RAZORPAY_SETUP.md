# Razorpay setup
Create live/test keys and a webhook pointing to `/api/billing/razorpay/webhook`. Set the three Razorpay environment variables, select payment authorization/capture/failure/refund and subscription lifecycle events, and use the identical webhook secret. Create the local subscription with its Razorpay subscription ID before accepting events. The endpoint verifies the raw body HMAC, updates local payment/subscription state transactionally, and records Razorpay's event ID for idempotency before acknowledging it. Complete a test-mode purchase, refund, and failed-payment rehearsal before live activation.
